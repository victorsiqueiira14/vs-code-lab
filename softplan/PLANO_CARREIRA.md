# Plano de Carreira — rumo a R$ 8.000+ líquidos

> Objetivo: em 6 a 9 meses, estar pronto para vagas que paguem **R$ 8.000+ líquidos/mês**
> (≈ R$ 10.500–11.500 brutos CLT, ou ≈ R$ 9.500–10.500/mês como PJ, conforme impostos).

## Ponto de partida (diagnóstico)

**Hoje:** suporte ao **SAJ PG5** no cliente **TJCE** pela Softplan — atendimento a usuários
(varas), treinamento, resolução de chamados no SCCD (Demanda/Causa/Solução) e construção de
**fluxos de trabalho** no sistema.

| Pontos fortes | Pontos a desenvolver |
|---|---|
| Conhecimento de negócio jurídico/judiciário (raro e valioso) | Trabalho reativo (fila de chamados), pouco visível |
| Comunicação com usuário final e treinamento | Profundidade técnica comprovável (SQL, dados, automação) |
| Fluxos de trabalho = lógica de processos / BPM | Inglês |
| Resolução de problemas com método (D/C/S) | Portfólio, LinkedIn e currículo orientados a resultado |
| Já usa IA no trabalho | Métricas do próprio trabalho (números para o currículo) |

## Trilha escolhida

**Principal: Analista de Suporte N3 / Application Support / Analista de Sistemas** com SQL forte,
automação e inglês → abre vagas nacionais melhores **e** vagas remotas internacionais (pagas em
dólar), que é o caminho mais rápido para "furar a bolha".

**Plano B (paralelo, mesma base): Analista de Dados / BI** (SQL + Power BI + noções de Python).

Base comum às duas: **SQL + inglês + resultados mensuráveis**.

## Fases

### Meses 1–2 — Base
- [ ] **SQL** do zero ao intermediário: SELECT, JOINs, GROUP BY, subqueries, CTEs, funções de janela.
      Praticar 30 min/dia (SQLBolt, LeetCode SQL 50, HackerRank SQL).
- [ ] **Inglês**: rotina diária de 30–45 min (ver seção abaixo). Fazer teste de nível (EF SET, gratuito) no início.
- [ ] **Registro de conquistas**: toda sexta, anotar em `softplan/notas/conquistas.md` (sem dados de cliente):
      problema, o que fez, resultado, número (ex.: "resolvi 32 chamados", "treinei 15 servidores").
- [ ] LinkedIn: título e "Sobre" reescritos (português + inglês).

### Meses 3–4 — Profundidade e prova
- [ ] SQL avançado + performance (índices, planos de execução) — ver `PLANO_DESENVOLVIMENTO.md`.
- [ ] **Power BI** básico (ou Power Automate, se for a trilha de automação).
- [ ] **1 projeto real no trabalho** que gere número: ex.: consulta que identifica processos com
      pendência de migração para o PJe antes de virarem chamado; modelo de resposta padronizado;
      treinamento gravado que reduz chamados repetidos.
- [ ] **Portfólio no GitHub** com 2–3 projetos com dados públicos/fictícios (ex.: painel de
      chamados simulado, análise de dados abertos do CNJ/DataJud).
- [ ] Inglês: começar a escrever e falar sobre o próprio trabalho em inglês.

### Meses 5–6 — Mercado
- [ ] Currículo em PT e EN orientado a resultados (método: ação + contexto + número).
- [ ] Simulações de entrevista (técnica, comportamental, em inglês) comigo.
- [ ] Aplicar: 5–10 vagas/semana, priorizando vagas que peçam **SQL + suporte/sistemas + inglês**.
- [ ] Mapear empresas de software jurídico, govtech e SaaS que valorizam experiência com Judiciário.

### Meses 7–9 — Ajuste
- [ ] Revisar o que as entrevistas pediram e não tinha; tapar as lacunas; continuar aplicando.

## Rotina semanal (≈ 1h30/dia útil + 2h no fim de semana)

| Quando | O quê | Tempo |
|---|---|---|
| Diário | SQL (exercício) | 30 min |
| Diário | Inglês (ouvir + falar/escrever) | 30–45 min |
| Diário | Usar o super prompt em 1 tarefa real do trabalho | no expediente |
| Sexta | `/carreira` + registrar conquistas da semana | 20 min |
| Sábado ou domingo | Projeto de portfólio / Power BI | 2 h |
| Mensal | Revisão do plano comigo (o que avançou, o que ajustar) | 30 min |

## Inglês — método prático

1. **Ouvir (diário, 15 min):** podcast/vídeo de tecnologia com legenda em inglês.
2. **Falar/escrever (diário, 15–30 min):** usar o modo `/ingles` comigo — conversa sobre o seu dia
   de trabalho, com correção.
3. **Vocabulário de trabalho:** traduzir para o inglês 1 resolução de chamado por dia
   (Demand/Root cause/Solution) — exatamente o tipo de texto de vagas de suporte internacional.
4. **Meta:** nível B2 conversacional para entrevistas em 6–9 meses.

| Candidaturas | 5–10 por semana a partir do mês 5 |
